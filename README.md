# Trotter

Trotter is being rebuilt from scratch.

- **Trotter**: the web UI over everything in this repo. Every AI agent here is also called Trotter.
- **trotter_trader**: a Rust algorithmic trading engine for NSE equities (coming).

## Archive

`archive/v0.5.0/` holds the original Next.js research app (also tagged `v0.5.0`). It is kept for reference only, so features can be looked up when they are remade. New code does not depend on it.
